# Triangle

## What you'll learn

- Creating vertex and index buffers and a `VertexArray`
- Compiling a vertex/fragment shader pair
- Drawing through an exception-safe `Renderer3D` scene scope

`common/ExampleSupport.hpp::triangleMesh()` shows the complete buffer layout.
The shaders live in this example's `assets/shaders` directory. VShade-owned
matrix uniforms are named `model`, `view`, and `projection`. Next: `03_input`.
